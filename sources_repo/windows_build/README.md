# Fabriquer Windows v0.1.1-beta

Sources de l'édition autonome. Installer Python 3.12 x64 sur une machine Windows
de fabrication, créer un environnement puis installer requirements.txt et exécuter
build_single.py avec cet environnement. Le résultat est dist_single/AeroDesign AI.exe.
Le destinataire final n'a besoin ni de Python ni des sources.

Le modèle embarqué reste figé ; son empreinte est contrôlée au lancement.
Les archives macOS précédentes ne sont pas actualisées par ce dossier Windows.
