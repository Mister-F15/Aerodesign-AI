Comprendre les résultats et le domaine du modèle +

Le dessin représente la géométrie réelle définie par le code NACA, sans simuler l’écoulement. L’incidence change la direction relative de l’air ; elle ne modifie pas la forme du profil.

Les prédictions ML sont autorisées aussi pour des NACA nouveaux dans le domaine élargi : cambrure de 0 à 6 %, position de 10 à 70 % pour les profils cambrés et épaisseur de 6 à 30 %. Les cas précisément non qualifiés de l’extension restent désactivés. La campagne initiale couvre 201 profils, complétés par une extension modérée ; le modèle apprend uniquement ceux du groupe d’apprentissage. Les Reynolds restent 1, 2 et 3 millions, de −4° à 8° par pas de 0,5°. La précision n’est pas garantie uniformément dans toutes ces bornes. CL et CD sont sans unité. Mach = 0 désigne ici une approximation incompressible, pas une vitesse nulle.

Modèle rééquilibré conservé dans le domaine initial. Sur le nouveau contrôle indépendant (107 cas qualifiés, 8 profils), l’écart moyen de CD passe de 1.38 % à 1.12 %. Sept profils sur huit s’améliorent. Sur les 943 cas du test précédent, la moyenne vaut 1.77 %, avec un maximum de 21.5 %. La précision reste variable, surtout pour les géométries extrêmes.

Extension modérée : familles retenues après test.

  • Combinaison de plusieurs extensions : exclue des prédictions
  • Cambrure de 7 à 8 % : exclue des prédictions
  • Position de cambrure à 80 % : exclue des prédictions
  • Épaisseur de 25 à 30 % : ouverte

Contrôle ciblé du 9 novembre 2026. Sur six scénarios d’optimisation, 32 cas sur 33 sont qualifiés par XFOIL. Sur ces 32 cas, l’écart moyen de CD vaut 0,66 %, avec un maximum de 3,12 %. Ces résultats ciblés ne garantissent pas la précision de chaque nouvelle prédiction. Le cas NACA 6715 à 0° et Re = 1 million reste exclu faute d’accord numérique suffisant.

Précision et confiance. Une erreur moyenne mesurée sur une famille de profils ne donne pas la probabilité que votre coefficient soit exact. Les profils extrêmes, les familles insuffisamment vérifiées et les cas de l’extension non qualifiés restent bloqués. Aucun pourcentage de confiance individuelle n’est calculé.

Des modèles ML figés estiment séparément CL et CD. La saisie déclenche uniquement une prédiction ML. Aucun calcul XFOIL n’est exécuté dans cette édition partageable. Le volet Optimiser classe les profils avec ces mêmes modèles, sans lancer XFOIL. L’illustration de l’écoulement utilise un modèle potentiel distinct et ne produit pas les coefficients ML.
